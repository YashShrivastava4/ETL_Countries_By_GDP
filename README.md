# 🌍 ETL Pipeline — Countries by GDP (Nominal)

A Python-based ETL (Extract, Transform, Load) pipeline that scrapes GDP data from Wikipedia, transforms it from Millions to Billions USD, and stores it in both a CSV file and a SQLite database. Built as part of a data engineering project simulating a real-world automated reporting workflow.

---

## 📁 Repository Structure

```
├── etl_project_gdp.py       # Main ETL script
├── Countries_by_GDP.csv     # Output: generated by the script
├── World_Economies.db       # Output: generated by the script (SQLite)
├── etl_project_log.txt      # Output: generated by the script (execution log)
└── README.md
```

> **Note:** `Countries_by_GDP.csv`, `World_Economies.db`, and `etl_project_log.txt` are **auto-generated outputs** — you do not need to create or modify them manually. They are produced every time `etl_project_gdp.py` runs.

## 🚀 How to Run

```bash
python etl_project_gdp.py
```

The script will:
1. Scrape the GDP table from Wikipedia
2. Clean and transform the data (Millions → Billions USD)
3. Save the result to `Countries_by_GDP.csv`
4. Load it into the `Countries_by_GDP` table in `World_Economies.db`
5. Run a SQL query to print all countries with GDP ≥ 100 Billion USD
6. Log all steps with timestamps to `etl_project_log.txt`

## 🌐 URL & Header Behaviour — Important Note

The script scrapes from:

```
https://en.wikipedia.org/wiki/List_of_countries_by_GDP_(nominal)
```

**When using the live Wikipedia URL** (as configured by default), HTTP headers are required because Wikipedia blocks requests that don't identify themselves as a browser:

```python
headers = {"User-Agent": "Mozilla/5.0"}
response = requests.get(url, headers=headers, timeout=10)
```

**If you switch to a Wayback Machine archive URL** (e.g., `https://web.archive.org/web/.../`), the `headers` argument can be omitted since archived pages don't enforce bot detection. Using an archive URL is also recommended if you want reproducible data, since the live page updates twice a year as the IMF releases new figures.

To switch to an archive URL, simply replace the `URL` constant at the top of `etl_project_gdp.py`:

```python
URL = "https://web.archive.org/web/<timestamp>/https://en.wikipedia.org/wiki/List_of_countries_by_GDP_(nominal)"
```

## 🗃️ Database Schema

**Database:** `World_Economies.db`  
**Table:** `Countries_by_GDP`

| Column           | Type    | Description                        |
|------------------|---------|------------------------------------|
| `Country`        | TEXT    | Country name                       |
| `GDP_USD_billion`| REAL    | GDP in Billion USD (rounded to 2dp)|

**Sample Query:**

```sql
SELECT * FROM Countries_by_GDP WHERE GDP_USD_billion >= 100;
```

## 📌 Notes

- Countries with missing or non-numeric GDP values (e.g., entries marked `—` or `N/A` on Wikipedia) are automatically dropped during transformation using `errors='coerce'` with `pd.to_numeric`.
- The script uses `if_exists="replace"` when writing to SQLite, so re-running it always gives a fresh, up-to-date table.
- The IMF updates GDP figures approximately twice per year, so this script can be scheduled (e.g., via cron) to keep the data current automatically.
